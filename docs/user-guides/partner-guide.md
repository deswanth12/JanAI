# 🤝 Partner Organization Guide

Guide for Colleges, NGOs, CSC VLE operators, and Banks utilizing the JanAI Partner Portal (`/partner`).

---

## 🔑 Key Features
- **Multi-Tenant Isolation**: Scoped by `org_id` (e.g. `ORG-AU-89410`).
- **Assisted Citizen Applications**: Submit verified welfare applications on behalf of rural citizens.
- **Batch Telemetry**: Track application processing status across nodal offices.

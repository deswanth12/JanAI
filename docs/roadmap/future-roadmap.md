# 🗺️ JanAI Product & Engineering Roadmap

Platform development roadmap following Semantic Versioning (SemVer).

---

## 📌 Release Schedule

- **`v1.0.x` (Pilot Stability Phase)**: Bug fixes, performance optimizations, and security patches ONLY.
- **`v1.1.0` (Post-Pilot Capability Phase)**:
  - WhatsApp OTP authentication provider.
  - Automated daily state gazette scraper.
  - Direct DigiLocker OAuth2 API integration.
- **`v2.0.0` (Nationwide Expansion Phase)**:
  - Multi-state deployment across 28 Indian States & 8 Union Territories.
  - Native offline-first mobile application (PWA / Android).

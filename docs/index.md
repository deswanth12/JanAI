- **Grounded Gazette RAG Engine**: Zero-hallucination AI reasoning backed by official central and state government gazette citations.
- **Enterprise Security**: Asymmetric RS256 RSA JWT signing, Argon2id passwords, Magic Byte file validation, and DPDP Act 2023 consent ledger.

# 📖 JanAI Enterprise Glossary

Definitions of technical, operational, and domain terms used in the JanAI ecosystem.

---

## 📚 Key Terms

- **ADR (Architecture Decision Record)**: Document capturing key technical choices (e.g. ADR 0001 Modular Monolith).
- **DPDP Act 2023**: Digital Personal Data Protection Act 2023 governing citizen consent and data privacy in India.
- **EventBus**: Asynchronous event dispatching system for decoupled domain communication.
- **Gazette**: Official government publication detailing state & central welfare scheme rules.
- **Magic Bytes**: First binary bytes of a file used to verify genuine file type (`%PDF-`, `\xFF\xD8\xFF`).
- **P95 Latency**: 95th percentile response latency metric (Target < 150ms).
- **PBAC**: Permission-Based Access Control enforcing role-scoped authorization.
- **RAG (Retrieval-Augmented Generation)**: Grounding AI LLM outputs in official gazette text.
- **SemVer**: Semantic Versioning (`MAJOR.MINOR.PATCH`).
- **SIEM**: Security Information and Event Management threat logging system.

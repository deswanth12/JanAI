# 🧪 Andhra Pradesh Pilot Handbook

Scope and governance guidelines for the initial pilot deployment across 26 Andhra Pradesh districts.

---

## 🎯 Target Targets & Formulas
- **Registration Completion**: `Registered Users ÷ Users Who Started` (**≥ 90%**)
- **Application Completion**: `Submitted Applications ÷ Started Applications` (**≥ 85%**)
- **AI RAG Latency**: `P95 over 24-hour window` (**< 150ms**)
- **SEV-1 Incidents**: Count in incident log (**0**)

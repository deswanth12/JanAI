# 📊 JanAI OS Administrator Manual

JanAI OS (`/admin`) is the enterprise internal command center for operations staff, security engineers, and executives.

---

## 🏛️ 3 Operational Pillars
1. **🏢 Operations Pillar**: AP Pilot Telemetry, System Diagnostics, User Control, Scheme Authoring, Document Verification Hub.
2. **🛡️ Security Pillar**: SIEM Threat Telemetry, Severity Matrix (🔴 Critical, 🟠 High, 🟡 Medium, 🔵 Info), RSA Key Rotation.
3. **📊 Executive Pillar**: Executive KPIs, Analytics Engine, System Settings (CEO Only).
